# elora-jewelry-store
A modern luxury jewelry store website built with HTML, CSS, and JavaScript.
# ✨ ÉLORA — Luxury Jewelry Store

> **Jewelry that speaks softly.**

ÉLORA is a modern luxury jewelry store website designed with an elegant, minimal, and editorial-inspired aesthetic. The website focuses on creating a premium shopping experience through refined typography, smooth interactions, clean layouts, and responsive design.

## 🌐 Live Website

**[View ÉLORA Live Website](https://kas232.github.io/elora-jewelry-store/)**

## 📌 Features

* 🛍️ Elegant luxury jewelry storefront
* 🔎 Product search functionality
* 🏷️ Product category filtering
* 🛒 Interactive shopping cart
* ❤️ Wishlist functionality
* 👗 Product details modal
* 📱 Fully responsive design
* ✨ Smooth animations and transitions
* 📩 Newsletter subscription section
* 💾 Cart and wishlist data stored using Local Storage
* 📱 Mobile-friendly navigation
* 🔔 Interactive toast notifications

## 🛠️ Technologies Used

* **HTML5** — Website structure
* **CSS3** — Styling, responsive design & animations
* **JavaScript (ES6+)** — Interactivity and functionality
* **Google Fonts** — Typography
* **Font Awesome** — Icons
* **Unsplash** — Product imagery

## 🚀 Getting Started

To run the project locally:

```bash
git clone https://github.com/Kas232/elora-jewelry-store.git
cd elora-jewelry-store
```

Then open `index.html` in your browser.
